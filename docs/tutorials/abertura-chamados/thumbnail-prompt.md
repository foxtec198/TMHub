Centered balanced composition, generous dark upper margin, clean silhouette readable at small thumbnail size, dimensional pedestal and green light reflections consistent with both references. Sharp, refined, uncluttered, no people.
No words, no letters, no numerals, no logos, no watermark, just symbolic UI lines and icons as in the reference covers. No books, no graduation caps. Output wide 16:9 landscape image.
